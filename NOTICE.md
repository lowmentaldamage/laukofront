## What is not taken from OpenFront

- No assets: no images, sounds, fonts, icons or map files from `resources/` or `proprietary/`.
- No branding, name, or UI look. Maps are generated by laukofront's own terrain generator.
- No server, account, cosmetics or monetisation code.

## Modified version

This is a modified version of OpenFront: the engine is translated from TypeScript to Rust, the
renderer and UI are new (Bevy), and the game is single-player against bots. Changes from the
original rules are listed in `DECISIONS.md`.
