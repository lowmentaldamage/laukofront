laukofront 1.0.1
================

A territorial strategy game for Windows: expand your land, ally with or betray AI nations, build
cities, ports and factories, sail boats and warships, and launch nukes. Win by holding 80% of the
land.

Run
---
Double-click laukofront.exe. The main menu opens: Play -> choose a map and players -> Start.
The exe also runs on its own; the "assets" folder only lets you change the game rules
(assets\config\game.toml).

If Windows SmartScreen or Smart App Control blocks the program, it is because the exe is not
signed. Choose "More info" -> "Run anyway", or build it yourself from the source.

Controls (press H in the game for the full list)
-------------------------------------------------
Left click            spawn, attack, send a boat across water
Right click anything  action menu: attack, send boat, build, warship, diplomacy
1 - 9                 attack size 10% - 90%
Q E F G V B           city, port, factory, defense post, missile silo, SAM
N  Z X C              warship, atom bomb, hydrogen bomb, MIRV
Space / F1-F3         pause / game speed
Esc                   cancel, or the pause menu (save, load, settings)
F5 / F9               save / load
Mouse wheel, right drag, WASD   camera

Settings and the save file are stored in %APPDATA%\laukofront\.
